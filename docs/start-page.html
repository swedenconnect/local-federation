Sweden Connect Local Federation

Links to the services of the local federation.

Before you start:
  • The links only work while the federation runs (docker compose up -d) and local.fed.swedenconnect.se is mapped to 127.0.0.1 in your hosts file.
  • All HTTPS services use the same self-signed certificate. Open one link per service and accept the browser warning before you log in, or a login stops halfway with a certificate error.
  • See Setting up the local federation, Services and OpenID Federation in the Local Federation for details.

Service Providers and Relying Parties

  • Test my eID start here
    Log in with an Identity Provider of the federation and see the attributes it sends. Also tries a signature.
    • Start page: https://local.fed.swedenconnect.se:11020/testmyeid
    • SP metadata: https://local.fed.swedenconnect.se:11020/testmyeid/metadata
    • Signature service metadata: https://local.fed.swedenconnect.se:11020/testmyeid/metadata/sign
    • RP entity configuration: https://local.fed.swedenconnect.se:11020/testmyeid/.well-known/openid-federation
  • Sweden Connect test client
    Build SAML and OpenID Connect authentication requests in detail and inspect the responses, assertions and tokens.
    • Start page: https://local.fed.swedenconnect.se:11030
    • Test SP 1 metadata: https://local.fed.swedenconnect.se:11030/saml/metadata/sp1
    • Test SignService 1 metadata: https://local.fed.swedenconnect.se:11030/saml/metadata/sign1
    • Test RP 1 entity configuration: https://local.fed.swedenconnect.se:11030/testrp1/.well-known/openid-federation
    • Federation status: https://local.fed.swedenconnect.se:11030/oidc/federation/info

OpenID Federation

  • Trust Anchor
    The root of the OpenID Federation, and its resolver. Entity identifier https://local.fed.swedenconnect.se:11040/trustanchor, key in config/common/oidf-trust-anchor.*.
    • Entity configuration: https://local.fed.swedenconnect.se:11040/trustanchor/.well-known/openid-federation
    • Subordinates: https://local.fed.swedenconnect.se:11040/trustanchor/subordinate_listing
    • All entities: https://local.fed.swedenconnect.se:11040/trustanchor/discovery?trust_anchor=...
    • Resolve endpoint: https://local.fed.swedenconnect.se:11040/trustanchor/resolve
  • RP Registration Intermediate
    Registers the Relying Parties. Entity identifier https://local.fed.swedenconnect.se:11040/im-reg-sc.
    • Entity configuration: https://local.fed.swedenconnect.se:11040/im-reg-sc/.well-known/openid-federation
    • Relying Parties: https://local.fed.swedenconnect.se:11040/im-reg-sc/subordinate_listing
  • OP Registration Intermediate
    Registers the OpenID Providers. Entity identifier https://local.fed.swedenconnect.se:11040/im-reg-sc-op.
    • Entity configuration: https://local.fed.swedenconnect.se:11040/im-reg-sc-op/.well-known/openid-federation
    • OpenID Providers: https://local.fed.swedenconnect.se:11040/im-reg-sc-op/subordinate_listing
  • Level of Assurance Trust Mark Issuer
    Issues the level of assurance trust marks. Entity identifier https://local.fed.swedenconnect.se:11040/tmi-loa.
    • Entity configuration: https://local.fed.swedenconnect.se:11040/tmi-loa/.well-known/openid-federation
    • Holders of LoA 3: https://local.fed.swedenconnect.se:11040/tmi-loa/trust_mark_listing?trust_mark_type=...
  • Contracts Trust Mark Issuer
    Issues the Sweden Connect contract trust marks. Entity identifier https://local.fed.swedenconnect.se:11040/tmi-contracts.
    • Entity configuration: https://local.fed.swedenconnect.se:11040/tmi-contracts/.well-known/openid-federation
    • Holders of eid-authorization-system: https://local.fed.swedenconnect.se:11040/tmi-contracts/trust_mark_listing?trust_mark_type=...
  • OpenID Federation service
    The service that hosts the entities above. See OpenID Federation in the Local Federation.
    • Health: https://local.fed.swedenconnect.se:11041/actuator/health
    Configuration: config/openid-federation

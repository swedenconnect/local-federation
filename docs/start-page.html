Sweden Connect Local Federation

Links to the services of the local federation.

Before you start:
  • The links only work while the federation runs (docker compose up -d) and local.fed.swedenconnect.se is mapped to 127.0.0.1 in your hosts file.
  • All HTTPS services use the same self-signed certificate, and your browser shows a warning for it the first time you open each service. Open the reference authentication server, Test my eID and the test client and accept the warning for each of them before you log in, or a login stops halfway with a certificate error.
  • See Setting up the local federation, Services and OpenID Federation in the Local Federation for details.

Service Providers and Relying Parties

  • Test my eID Start here

    https://local.fed.swedenconnect.se:11020/testmyeid

    Log in with an Identity Provider of the federation and see the attributes it sends. Also tries a signature.

    • SP metadata: https://local.fed.swedenconnect.se:11020/testmyeid/metadata

    • RP entity configuration: https://local.fed.swedenconnect.se:11020/testmyeid/.well-known/openid-federation

  • Sweden Connect Test Client

    https://local.fed.swedenconnect.se:11030

    Build SAML and OpenID Connect authentication requests in detail and inspect the responses, assertions and tokens.

    • Test SP 1 metadata: https://local.fed.swedenconnect.se:11030/saml/metadata/sp1
    • Test SignService 1 metadata: https://local.fed.swedenconnect.se:11030/saml/metadata/sign1
    • Test RP 1 entity configuration: https://local.fed.swedenconnect.se:11030/testrp1/.well-known/openid-federation
    • Test RP 2 entity configuration: https://local.fed.swedenconnect.se:11030/testrp2/.well-known/openid-federation
    • Test RP 3 entity configuration: https://local.fed.swedenconnect.se:11030/testrp3/.well-known/openid-federation
    • Federation status: https://local.fed.swedenconnect.se:11030/oidc/federation/info

OpenID Federation

    https://local.fed.swedenconnect.se:11040/trustanchor

    The root of the OpenID Federation, and its resolver. The address is its entity identifier. Key in config/common/oidf-trust-anchor.*.
